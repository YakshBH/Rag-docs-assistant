# Document sources

Add one entry for every PDF placed in `data/raw/`.

| Local filename | Official source URL | Publisher | Access date | Usage/license notes |
|---|---|---|---|---|
| example.pdf | https://example.gov/ | Publisher name | YYYY-MM-DD | Check the source's terms |

Start with a small set of public documents. Keep original PDFs unchanged and verify the source and usage terms before redistributing them.
